# ADR-0015：发布修订锁定场景契约版本

- **状态**：已接受
- **日期**：2026-09-23
- **关联**：ADR-0006、ADR-0012；系统设计草案 §5、§6

## 上下文

修订保存 `ScenarioCode + ContractVersion`。宿主可在同一场景注册多个契约版本；发布修订不可变。自动把旧修订解释为新契约会改变入口、出口和类型语义。

## 决策

修订创建时锁定准确的契约版本，保存、试算、发布及运行均按该版本解析。宿主必须保留仍被活动或历史发布修订引用的契约版本；缺失时返回明确的契约不可用错误，不自动迁移或推断兼容。升级须创建基于旧修订的新草稿并显式选择新版本，后续阶段实现升级操作和差异校验。

## 考虑过的替代方案

- 始终使用最新契约：旧修订的执行语义会随宿主部署改变。
- 自动推断向后兼容：类型、默认值和出口义务难以可靠推断。

## 后果

- 注册表支持同一场景的多个版本，按三元组唯一。
- 运行时不能静默替换契约版本；宿主移除旧版本前须检查引用。
- 首批模型 API 只允许使用明确注册的版本，不实现自动升级。
