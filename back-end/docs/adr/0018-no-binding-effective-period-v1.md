# ADR-0018：首版绑定不包含生效期

- **状态**：已接受
- **日期**：2026-09-23
- **关联**：ADR-0011；产品设计草案 §6.5

## 上下文

当前没有已确认的按时间切换绑定需求。加入生效期需要定义 UTC 时刻或业务日期、时区、试算时间、相邻区间和重叠发布校验。

## 决策

首版 `ScenarioBinding` 不保存 `EffectiveFrom/EffectiveTo`；绑定随所属发布修订的激活和回滚生效。需要排期切换时再定义完整时间语义和迁移方案。

## 考虑过的替代方案

- 先存字段但暂不使用：容易被调用方误认为已生效。
- 默认使用服务器本地时间：多宿主和跨时区行为不稳定。

## 后果

- 运行请求不需要隐含的“当前时间”参与绑定选择。
- 未来的排期能力必须独立设计，不可仅补两个日期字段。
