# ADR-0020：区间与同类型候选列表出口

- **状态**：已接受
- **日期**：2026-10-14
- **关联**：ADR-0012、ADR-0017；[输出值契约](../architecture/output-values.md)

## 决策

在 RuleTypeDescriptor 中增加 Shape，保留 RuleValueKind 作为基础类型。契约出口可以是 Scalar、NumericRange 或 List；入口、条件场景输入和中间变量保持单值。数值区间为非空有限闭区间，列表为按维护顺序返回的 1–100 个同类型、非空且不重复的候选值。

赋值通过 Constant 或 Expression 保存：常量使用 JSON 对象或数组，计算型结果使用 range/list 根节点，各子表达式复用现有单值 AST。复合出口暂不参与条件或后续单值公式，不增加任意对象、嵌套列表或跨规则聚合语义。

项目处于开发阶段且尚无系统集成，直接更新类型、数据库模型和哈希语义，无需旧数据兼容分支。已发布修订不可编辑仍是当前产品行为。

## 后果

保存、完整校验、试算、发布门禁和运行执行统一验证输出结构。Shape 与复合赋值内容进入发布快照和哈希；原型提供端点和候选项编辑。详细格式与约束以输出值契约为准。
