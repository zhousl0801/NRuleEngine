# ADR-0022：统一到 .NET 8 / ABP 8.0.4

- **状态**：已接受
- **日期**：2026-10-16
- **关联**：取代 ADR-0014 中的框架版本决策；[兼容说明](../architecture/framework-compatibility.md)

## 上下文

现有组件使用 net10.0 / ABP 10.6.0，目标接入宿主使用 .NET 8 / ABP 8.0.4。当前组件尚未被其他系统集成。

## 决策

所有项目、测试和本地 Host 统一使用 net8.0 / ABP 8.0.4，SDK、解决方案、CI 和容器配置同步采用 .NET 8。替换 .NET 10 专有 JSON API，并保持原有门禁和并发语义。

## 考虑过的替代方案

- 同时维护两套 ABP 主版本会增加依赖与验证成本；当前没有已集成用户，不采用多目标构建。
- 不要求接入方仅为使用引擎升级整个 ODS；也不在本次增加独立生产规则服务和网络依赖。

## 后果

所有项目使用同一套 .NET 8 依赖与工具链，需验证 JSON 比较、聚合并发及发布行为。ODS 适配继续在 ODS 仓库实施，实际宿主引用、数据库迁移和业务对照仍需在后续接入时验证。
