# 规则维护能力完成计划

> 状态：后端组件代码已实现，宿主联调未执行；2026-10-10 依据[产品设计草案](NRuleEngine-产品设计草案.md)整理。

## 目标与边界

补齐产品草案中尚未落地的日常维护能力：复制规则模型、维护可编辑变量属性、查看变量及待删除对象的引用与影响、在安全检查后删除草稿中间变量。沿用现有 ABP 分层、`NRuleEngine.Manage` 权限、Revision 并发戳和已发布修订不可变约束。模型停用沿用归档，不增加模型物理删除；[旧规则适配新场景定义](场景定义升级计划.md)、跨环境导入导出及前端编制台属于其他阶段。

实施前已有创建与归档模型、复制修订为草稿、增加与重命名中间变量、删除草稿规则及赋值的 API。以下阶段记录本次补齐的能力与验收点；相关接口见[后端 README](../../README.md)。

## 阶段一：补齐变量属性维护

1. 属性可编辑矩阵：契约变量的编码、名称、方向、类型、单位和必需性由锁定的场景契约决定；草稿中的契约入口变量允许配置默认值，用户中间变量允许维护名称、默认值、单位和精度。精度修改仅适用于用户中间变量，契约变量的精度不可通过维护 API 改动。
2. 在 `RuleModels` 的 DTO、应用服务、领域对象和 HTTP 控制器中增加草稿变量更新能力，返回更新后的修订和新并发戳；只操作 `Draft`，拒绝过期并发戳。默认值与单位、Decimal 精度使用独立操作，避免省略字段时清空精度。按现有类型校验规则检查默认值和精度，更新时重新校验受影响的常量赋值；表达式运行结果继续由发布门禁验证。
3. 在试算和生产执行共用的求值路径中使用默认值：缺少入口且已配置默认值时使用默认值；中间变量在读取前尚未赋值且已配置默认值时使用默认值。默认初始值不计入规则赋值次数。缺少默认值仍按现有缺失或未赋值错误处理；显式传入的 JSON `null` 不视为缺少入口，仍按变量可空性校验。未知入口仍严格拒绝。发布门禁用例通过相同的试算路径验证这些语义。
4. 在变量详情 DTO 中返回可维护属性；检查 EF 映射、修订复制和发布内容哈希对这些字段的一致性。变更执行语义的字段须随修订发布，不能改动历史发布快照。

验收：可维护属性可保存、读取并复制到新草稿；缺失入口和读取前未赋值的中间变量按已配置默认值参与试算、门禁和生产执行；无默认值、显式 `null` 和未知入口各按对应规则处理。非法默认值或精度、修改契约变量精度或其他锁定字段、修改已发布修订及旧并发戳均被拒绝；发布后运行结果与该修订语义一致。

## 阶段二：引用与影响分析

1. 基于当前修订中的 `StableKey` 扫描规则条件 AST、赋值表达式和赋值目标，提供变量引用查询，返回引用类别、对象标识和可定位路径。发布门禁用例按入口与出口编码保存，需分别报告相关的用例引用或规则变更带来的间接影响；历史发布修订只作只读展示。
2. 复用相同的引用分析能力，为删除中间变量、删除规则或赋值、归档模型提供操作前影响摘要。变量存在引用时阻止删除；规则、赋值等其他对象的删除及模型归档只提示影响，不因引用而阻止操作。归档提示须说明活动修订及运行选择会受到的影响；原有草稿状态、权限和并发检查仍然有效。
3. 查询结果与删除检查都按修订快照和并发戳确定范围，防止查询后草稿变化造成静默误删。影响分析仅返回有权限查看的规则内容，不扩大当前数据权限。

验收：条件、表达式、赋值目标中的直接引用和门禁用例的相关影响都能定位；间接影响可追溯；被引用变量不能删除，其他对象删除和归档仅提示影响；引用分析后并发修改会使旧写入请求失败；已发布历史保持可查询且不被修改。

## 阶段三：安全删除与模型复制

1. 增加草稿中间变量删除接口。仅允许删除 `UserDefined` 的 `Intermediate`；存在阻塞引用时返回结构化影响并拒绝删除，不自动清理规则。删除后再创建同名变量须生成新的 `StableKey`。继续使用现有草稿子实体物理删除策略，不触碰已发布修订。
2. 增加规则模型复制用例：调用方指定新模型编码和展示信息，从指定源修订复制内容，生成新模型及首个草稿，不激活或发布。跨模型复制继承源修订的变量 `StableKey`、锁定的场景契约版本和发布门禁用例内容；新模型、修订及子实体仍使用新的数据库标识。验证新模型编码唯一性及源修订所属场景契约仍可用。
3. 为新增接口补充契约、领域、应用服务和必要的 EF 测试；最后运行受影响项目构建与完整解决方案测试，并核对 README 的 API 清单。

验收：无引用的草稿中间变量可删除，存在引用或并发冲突时不能删除；模型复制后 `StableKey` 和门禁用例内容继承，源模型、源修订和活动发布状态不变，新模型可独立编制、校验和发布。

## 已确定的业务规则与实施核对

- 缺少入口和读取前未赋值的中间变量使用已配置默认值；显式 `null` 沿用可空性校验。默认值不计入多次写入策略，试算、发布门禁和生产执行使用同一求值路径。
- 精度修改仅适用于用户中间变量；更新时重新校验现有常量赋值，表达式运行结果由发布门禁验证。
- 跨模型复制继承变量 `StableKey` 和门禁用例内容；同一模型内复制草稿继续保持现有稳定身份规则。
- 变量有引用时阻止删除；归档和其他对象删除只提示影响，不放宽权限、草稿状态或并发约束。

本次只开放契约入口默认值；契约变量展示名称与单位不提供维护覆盖。组件层自动化测试已覆盖默认值、引用阻断、复制继承及发布执行；宿主迁移、鉴权和 HTTP 联调仍需在接入时验证。
