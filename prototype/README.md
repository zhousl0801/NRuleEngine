# NRuleEngine 交互原型

本目录是独立的静态交互演示，不需要后端或前端构建。产品范围见[产品功能说明](../back-end/docs/product/features.md)，服务端协议见[API 参考](../back-end/docs/reference/api.md)。页面未调用真实 API，所有保存和试算均为浏览器本地行为。

## 启动与检查

在仓库根目录执行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

访问 `http://127.0.0.1:4173`，入口为 [index.html](index.html)，单条规则编辑位于 [rule-maintenance.html](rule-maintenance.html)。会话状态跨页面共享，建议通过同一 HTTP 来源预览。

执行浏览器侧语义检查：

```bash
node --test prototype/tests/rule-execution.test.cjs
```

测试覆盖执行顺序、写入策略、上下文共享与行隔离、出口完整性、失败清空结果、数量限制及设置隔离，不代替后端测试或真实浏览器端到端验收。

## 信息结构与主流程

层级为 `App → 场景 → 规则集（RuleModel）→ 修订 → 规则 → 赋值`。规则集一一对应后端模型，不是额外容器；条件集使用独立编辑流程。

| 区域 | 交互 |
| --- | --- |
| 场景 | 按规则集/条件集分区搜索与查看只读说明，进入带场景筛选的列表 |
| 列表 | 跨场景筛选；明确场景后创建；查看线上/草稿修订；复制规则集、创建草稿及归档 |
| 规则集详情 | 规则、变量、绑定、执行设置、发布校验规则、版本 |
| 规则维护 | 嵌套 AND/OR 条件组；逐条保存规则和赋值；删除前查看影响 |
| 校验与试算 | 使用已保存内容预览，按行展示结果、来源规则和可展开的过程/JSON |
| 条件集 | 编制示例布尔条件及优先级；明确场景和候选后预览 AllMatches/FirstMatch |

规则维护流程为：选择规则集与草稿 → 新增或选择规则 → 编辑并保存条件 → 逐条保存赋值 → 完整校验 → 试算 → 返回详情维护门禁和检查发布条件。“下一步”只切换步骤，不表示自动保存。原型的发布检查不会真正发布或回滚。

列表保留场景、搜索和维护状态范围；详情内仅切换同场景集合。无效场景或缺少集合标识时显示对应提示/返回列表，不静默切换业务范围。新建从空规则和绑定开始，复制明确来源快照；线上与归档修订只读，未保存内容离开前提示。

## 条件、赋值与执行设置

条件组逐层选择 AND/OR，可表达 `(A AND B) OR (C AND D)`。主组无条件表示始终满足，空子组不能保存。公式栏支持示例 Decimal 变量、数字、四则运算及括号，快捷按钮在光标处插入；页面生成 AST，原始文本不直接交给服务端执行。可选小数位生成外层 Round。

区间分别编辑两个端点，列表逐项维护及排序，端点和元素可选常量或标量公式。整体保存为一条赋值，正式边界见[表达式与值结构](../back-end/docs/reference/expressions.md)。

执行设置随修订保存，单行允许 FirstMatch/Sequential，多行固定 CollectMatches；顺序计算选择重复写入策略。保存设置使草稿门禁待重新验证，复制及从线上建草稿继承设置。多行预览保持字段对应关系，各行隔离；任一后续计算失败均不返回部分成功行。

可从“精整宽度修正”的“分步宽度计算”体验：入口宽度 120、产品类别 A，顺序计算且后续覆盖得到 132.5，保留首次写入得到 132；首条命中模式在第一条后停止。多行示例位于“候选规格计算”。这些是本地样例，不是已发布业务规则。

## 状态、界面与交互

已保存状态保存在当前标签页 sessionStorage，同标签页刷新保留，关闭后结束；未保存编辑仅在当前页面。存储不可用时退回页内状态，不能据此保证跨页保留。状态隔离到场景、集合与修订，不写项目数据库。

页面使用中文产品文案，编码、修订号及公式保留原格式；界面不展示测试应用或演示提示，真实服务边界在本文说明。场景代码和类型说明只读，ContractVersion 用于内部契约，不设计维护者版本选择。输入/结果/绑定范围分开展示，不能将可空性当作可省略输入。

共享 design-system.css 与 interface.js 统一颜色、字号、间距、组件状态、通知和响应式表格。桌面保留侧栏，手机采用底部导航和可展开规则列表；步骤支持方向键、Home/End，删除对话框默认聚焦取消，关闭恢复焦点，错误提示关联字段，动画尊重减少动态效果设置。

## 正式接入缺口

- 新建、复制、保存、归档、并发冲突和发布检查均是本地演示；未实现真实请求加载、失败重试、服务端并发恢复及发布读回。
- 后端条件集缺少按应用/场景列表查询，原型的列表不证明该 API 已存在；没有条件集跨集合复制入口。
- 场景名称和用途说明、变量/维度候选使用本地示例数据。后端未提供丰富场景说明、动态绑定候选值和函数/类型目录。
- 条件集编辑只覆盖当前样例字段，尚非完整通用 AST 编辑器；门禁样本维护和发布结果也未与服务端连接。
- **单行无规则命中存在语义差异**：原型测试仍期待失败，后端所有模式已返回 NotMatched。正式接入前须统一行为，不能用本地预览判断业务成功。
- JavaScript 数值预览不保证与服务端 decimal、Round、精度、完整依赖/类型校验一致，也不模拟跨模型绑定裁决或证明服务端 65,536 字节限额行为。
- 目前没有完整生产 Trace、正式权限验证或设备/辅助技术验收。静态/Node 检查、浏览器交互验证及后端联调需分别记录实际完成范围。
